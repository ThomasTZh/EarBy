# Security policy

Please report security vulnerabilities privately through GitHub's security advisory feature or by
email to thomas.t.zhang@outlook.com. Do not open a public issue for an exploitable vulnerability
before a fix is available.

EarBy has no INTERNET permission and no backend. High-value reports include a way to make the app
read unexpected files, bypass the preset/document bounds, expose hidden answers before they are
consumed, or cause unbounded resource use through a session or imported document.

Do not include device serials, personal file paths, signing material or other sensitive data in a
report. We will acknowledge a report, reproduce it on the supported phone/API range, and document
the fix.
