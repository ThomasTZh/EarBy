## MATLAB SoundFont

`f3326f4c53c52a521bce7e9e2932edb9e34807f85a96b391eb224a5a0b499705`) is generated from the
project’s own additive synthesis code in `synthNotes/` with the V4 dark calibration selected by
the owner on 2026-11-08. The derived EARP1 pack `earby-string-pack.bin` (21,126,760 bytes,
SHA-256 `f2e14a32c252c5d94ec5f1b7f8cbf63da6ff7a2c08afb49470af591cc6c05462`) contains the same
88 project-generated one-shots. There is no third-party sample content. The release record must
include:

- MATLAB release and toolboxes used;
- generator commit/source hash;
- synthesis parameters and final SoundFont SHA-256;
- a statement that MATLAB itself and MathWorks code are not distributed.

The project’s SoundFont is licensed CC BY 4.0. The MATLAB license should be checked before
commercial distribution; the app does not ship MATLAB.

## Separator clip

`app/src/main/assets/separator/original-separator.wav` is a rendered derivative of the
**MuseScore General v0.2** SoundFont, which is distributed under the **MIT license**. The record
below is complete: source, licence, author, date and rendering process are known, and the shipped
bytes were reproduced bit-exactly from the hash-verified upstream font on 2026-11-08. No
separator replacement is needed; a new clip would be a separate asset requiring its own review.

- Source file: `MuseScore_General.sf2` v0.2 (13 May 2020), upstream
  `https://ftp.osuosl.org/pub/musescore/soundfont/MuseScore_General/MuseScore_General.sf2`,
  215,614,036 bytes, SHA-256
  `ee51d2c4b1525e70f19a45909c4fd7a2e26d91d115fa89dbf5a6bc413d8b9bf3`. The SoundFont is a
  development-time input and is not part of this repository. Its RIFF `INFO` metadata names
  `MuseScore_General v0.2` and states “Released under the MIT license. Please see
  `MuseScore_General-License.md` for more information.”
- Preset and samples: bank 0 / program 0, “Grand Piano”. Its credit in the upstream
  `MuseScore_General_Sample_Sources.csv` is “Splendid Grand” for AKAI S5000, samples by AKAI,
  edited by S. Christian Collins, with “Original License: Public Domain (confirmed via AKAI
  rep.)”. The font as a whole is published under MIT; that CSV records the per-instrument sample
  credits and their original licences.
- Licence text: `LICENSES/MuseScore_General-MIT.txt`, the verbatim upstream
  `MuseScore_General_License.md` (3,419 bytes, SHA-256
  `5ad8d737e13c7f01f5b9674872a82a92b4ba253603e8ed14b9db12293550b4b9`). It requires the
  acknowledgements and copyright notices to be included in any derivative work: FluidR3 by Frank
  Wen (c) 2000-02; FluidR3Mono conversion by Michael Cowgill (c) 2014-17; MuseScore General
  adaptation by S. Christian Collins (c) 2018-19; Temple Blocks by Ethan Winer (c) 2002; Drumline
  Cymbals by Michael Schorsch (c) 2016. Those acknowledgements are carried in
  `THIRD_PARTY_NOTICES.md`.
- Musical content and rendering process: the fixed C6/G6 cue. C6 (MIDI 84) sounds from 0.000 to
  0.120 s, then an 80 ms gap, then G6 (MIDI 91) from 0.200 to 0.320 s; note-on velocity 96, gain
  1.0, 32-voice polyphony, 48 kHz mono, and a 5 ms linear final fade per note with the release
  tails cleared in the gap. The project owner rendered it on 2026-10-18 with the development
  harness `separator_render.cpp` (SHA-256
  `09d7790a1dbaae0a683a7ec82dfaa55892b35db25e73cc3d46d6f478c1d9f1c6`) through the app’s
  then-current native SoundFont renderer (replaced in V4 by the in-project sample player), wrote a
  float WAV, and converted it to PCM16 little-endian with FFmpeg. It was first committed in 0.9.21
  (commit `9fd9945`, 2026-10-20). The harness is development-only and stays in ignored local
  storage; it linked the app’s own native renderer of the time, so the cue used the same engine
  path as the instrument then.
- Rendered asset: 30,798 bytes, RIFF/WAVE PCM16, 48 kHz mono, 15,360 frames (0.320 s), peak
  -18.46 dBFS, RMS -28.18 dBFS, mean -2.6e-5 of full scale, SHA-256
  `ed935306de57c8466d7d4a096817624d945ac0858771251adbc2d741c8ac96a6`.
- Reproduction: running the harness’s note table against the hash-verified upstream font and
  converting the float output to PCM16 reproduces the shipped file byte for byte (SHA-256 match,
  verified 2026-11-08). The clip therefore needs no licence exception; the project adds no further
  restriction beyond the upstream MIT terms and their acknowledgement requirement.
- Review: the owner accepted the shipped cue by ear on 2026-11-08 (see `docs/audio/ASSETS.md`);
  the 0.9.21 listening round had already kept the original cue. No further human item remains for
  this asset.
